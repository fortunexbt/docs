The [recipes](/recipes) rerun one claim each from a fresh clone: Tablebeam's comparison with pandas, SQLite and DuckDB, the BoundaryBench report from committed Claude Code traces, a local MUTX policy check, and seeded frames from Terminal Starfield and ckitty.

## Status labels

| Label | It means | It does not mean |
|---|---|---|
| **Shipped** | A release or public use path exists | Every possible deployment is supported |
| **Verified** | A reproducible check or inspectable artifact backs the claim | A badge passed once |
| **Experiment** | Real code runs inside a deliberately limited envelope | Production-ready |
| **Simulated** | The behaviour is mocked or emulated on purpose | Connected to the named external system |
| **Planned** | The direction is written down and not implemented | Almost done |

A label attaches to a specific surface, such as a release, a hosted demo or a command, not to a whole project.
