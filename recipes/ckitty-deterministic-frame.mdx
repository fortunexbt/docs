## Prerequisites

- Git.
- A C11 compiler (`cc`).
- Wide-character ncurses headers and libm. On Debian or Ubuntu install `libncurses-dev`, on Fedora `ncurses-devel`, on macOS `brew install ncurses`. The Makefile finds Homebrew's ncurses through `brew --prefix ncurses`.
- Python 3 for the pseudo-terminal test in `make check`.

## 1. Build and check

```bash
git clone https://github.com/fortunexbt/ckitty.git
cd ckitty
make && make check
```

`make` builds one `ckitty` binary from `src/ckitty.c` and `src/ckitty_core.c`, linked against real ncurses. `make check` then runs three suites. On 23 October 2026 at commit [`cd7d1fb`](https://github.com/fortunexbt/ckitty/tree/cd7d1fb328a6901c13ab2ded7716800e7a712d15) on macOS they printed:

```text
./ckitty_test
OK
tests/test_cli.sh ./ckitty
CLI OK
python3 tests/test_resize.py ./ckitty
TERMINAL OK (controls, palettes, Unicode messages, compact help, quiet, pause/help, slow timing, live progress, screensaver, resizes)
```

## 2. Render the same kitty twice

```bash
ckitty_capture_dir="$(mktemp -d)"

./ckitty --dump --seed 123 sit > "$ckitty_capture_dir/kitty-a.txt"
./ckitty --dump --seed 123 sit > "$ckitty_capture_dir/kitty-b.txt"

cmp "$ckitty_capture_dir/kitty-a.txt" "$ckitty_capture_dir/kitty-b.txt" && echo identical
cat "$ckitty_capture_dir/kitty-a.txt"
```

`--dump` seeds the core RNG, renders frame 0 onto an 80×24 canvas, prints the canvas trimmed to the cat, and exits before `initscr()`. The output has no ANSI escapes. In the run above both files were 120 bytes, `cmp` exited 0, and the frame was:

```text
     /\___/\
    ( o   o )
   -\   ^   /-
     )`---'(
    /  | |  \
 __( ` | | ` )
(   \__|_|__/
  `-(__)(__)
```

Each line in the file also keeps trailing spaces up to the cat's widest row. To pick a different moment or canvas, add `--frame N`, `--width W` or `--height H`. Themes don't change dump output.

## 3. Run the sanitizers

```bash
make sanitize
```

This cleans, rebuilds with `-fsanitize=address,undefined`, and runs `make check` again. It printed the same `OK`, `CLI OK` and `TERMINAL OK` lines. Run `make clean && make` afterwards if you want an uninstrumented binary back.

## 4. Meet the interactive kitty

```bash
./ckitty
```

Press <kbd>Space</kbd> to cycle poses, <kbd>1</kbd> to <kbd>4</kbd> for sit, sleep, play and walk, <kbd>N</kbd> for a new kitty, <kbd>T</kbd> for the next palette, <kbd>?</kbd> for help, and <kbd>Q</kbd> to quit. The same program, compiled to WebAssembly, runs at [ckitty.vercel.app](https://ckitty.vercel.app).

## Expected evidence

- `cmp` exits 0 and the script prints `identical`.
- The dump contains plain characters with no escape sequences.
- `make check` prints `OK`, `CLI OK` and a `TERMINAL OK` line.
- `make sanitize` prints the same lines with no sanitizer report.

## This recipe does not prove

- That interactive animation repeats. It depends on keypresses and the clock.
- That the browser build behaves the same. It shares the core but swaps ncurses for `src/web_curses.c`. The Playwright key test (`make test-web`) is outside `make check`.
- That every compiler and platform supports the sanitizers, or that the build works beyond macOS and Linux.

Remove the captures when you're done:

```bash
rm -r "$ckitty_capture_dir"
```
